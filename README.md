# Avocado Sales & Produce Market Analysis

## Project Overview
This project analyzes weekly Hass avocado retail sales data from **2015–2018**, originally published by the **Hass Avocado Board**.

The analysis focuses on average price trends, total sales volume, organic vs. conventional avocados, regional differences, time-based patterns, probability questions, confidence intervals, hypothesis testing, and chi-square analysis.

## Data Source
**Original source:** Hass Avocado Board — retail volume and price data for Hass avocados.

The dataset contains weekly retail scan information, including fields such as Date, AveragePrice, Total Volume, type, year, region, and PLU-level sales volumes.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Jupyter Notebook / Google Colab.
